## Recent improvements (unreleased — ships in the next build)

- 🖼 **Drop a photo on the composer** — Finder/Explorer onto the chat bar or Waifu Coder, or the attach button. One photo per send. The picker is still there if you prefer it.

- ↵ **Enter sends the task** — Shift+Enter still makes a new line. The last-write preview has an X to dismiss it.

- 🧠 **Thought chevron works while they are still thinking** — tap to collapse (or expand) the live think block; the timer keeps running. It used to ignore you until the next think started.

- 🖥️ **Waifu Coder** — Sit down with a coworker and she loops tools in that folder, in the same chat bubbles and portrait sidebar as a normal chat. Every folder you've used shows as its own glowing card — three folders, three cards. **New porch** picks the folder, then the character (search the coworker grid by name or tag). The card appears as soon as you sit down, even before a chat turn. MCP tools from Settings actually toggles — clone coding-agent servers (Desktop Commander `list_directory` / `get_prompts`) are dropped so she uses Waifu Coder's own read/glob/bash and does not paste "New to Desktop Commander?" onboarding. Nested **task** (explore or general, one level) and `/workflow` JSON pipelines in `.waifu/workflows` (not a scripting language). Installed skills live in `~/.waifu/skills` (Windows `%USERPROFILE%\.waifu\skills`, and this folder's `.waifu/skills`); Claude/Grok/Hermes SKILL.md files on the machine still load by name. The context bar counts the system prompt. **Preserve thinking** in Harness (off by default) sends prior thought tokens back on the next turn; off drops them. Last-write preview stays a short clip so a fat file cannot blow the layout. Language help is the translate button in the top bar. Hidden folders stay off the picker until you ask. The coworker is the V2 card you picked — name and personality on top, a couple of talk samples, then a coding job (no chat scenario). Type `/` for a command menu (help, skills, plan/build/yolo, stop, **code review**, test, workflow…). `/review` and `/code-review` are the same hostile folder review. **Skills** in the sidebar is an allowlisted HTTPS catalog (Anthropic, Vercel, Superpowers) — Refresh, Install, or say “install the pdf skill”. Recursive `rm -rf` of `/`, `*`, `.`, or home is hard-denied even in Yolo. A big **Stop** appears while she is running. She is told to **search** (web_search, webfetch, or an MCP search tool) before claiming a Flutter/Dart version does not exist. Deleting a session asks first. The task box grows as you type (up to ten lines) so a long prompt does not vanish. Each think/tool/talk cycle is its own bubble so speech is not wiped, and tools are a stacked log instead of a chip pile. Thought streams live. Main Settings still has temperature and model swap; the realism stack is gone and that pane is harness / MCP / skills / tasks instead. Not Claude Code; not for code you cannot afford to lose. Desktop only.

- 🔌 **MCP tools: tap Docker, don't invent a URL** — Settings → Porch Life. Docker Desktop does not give Front Porch an address; the Docker chip fills the local gateway, Find local looks on port 8811, and a token only appears if the server asks. A success is "Connected — 110 tools", not a wall of names. The URL, switch, and token survive an app restart without asking for your Mac password. Same on the phone.
