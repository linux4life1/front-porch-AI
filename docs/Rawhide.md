# Rawhide — What's New (Nightlies)

These notes feed the in-app "Update Available" dialog for Rawhide / cutting-edge builds.
**Only list what landed after the last shipped nightly.** Clear this section when a new nightly goes out — delete the old bullets; do not accumulate them.

Last shipped nightly: `rawhide.20261006.fbe655b`. Everything below is unreleased.

## Recent improvements (unreleased — ships in the next build)

- ⌨️ **Typing in the AI Character Creator no longer lags on Windows** — every key used to save the whole creator form, which on Windows rewrote the settings file dozens of times per letter. Typing now saves once you pause, and only what changed.
- 🪟 **A file window that fails now says so** — when the window for choosing a file or folder, or for saving, doesn't appear, you get a plain explanation with a Try again button instead of a click that does nothing. A folder the app can't read says so too. And exporting a character, place, chat or story whose name has characters Windows doesn't allow in a file name (such as `:` or `?`) now opens the save window instead of waiting forever.
- **The AI creator has a Greetings step**, on the desktop and the phone. After a character is generated, each greeting gets its own card: edit it, rewrite it (steer the rewrite with one line, like "start at the harbor at dawn"), delete an alternate, or add another one, written straight away. On the desktop, rewriting the first message leaves the outfit as it was, and the Realism step offers to read it again from the new opening.
- 🗂️ **Folders follow your sort** — the folders at the top of the library now sort the same way as the cards. Name puts them A→Z; Recent Activity, Import Date and Messages Sent go by what is inside each folder, subfolders included (its newest chat, its newest card, or its total messages), with empty folders last. Group chats sort A→Z. In the desktop app for now.
- 🔎 **Search where you mean to** — the button at the start of the library search box now works at the top level too: pick **Everywhere** or **Top level only** (just the cards that are in no folder, which is where imported cards land). Inside a folder, **This Folder Only** no longer finds cards in its subfolders; **Folder & Subfolders** does that. The app remembers your choice, like the sort. In the desktop app for now.
- ☑️ **Select all** — Multi-select and Organize into folders now have **Select all** and **Select none** at the top. Select all picks every card on screen, so after a search it picks only what the search found. Ctrl+A (Cmd+A on a Mac) does the same once you have clicked in the grid, and Esc clears the selection. Cards you picked stay picked when a new search or folder hides them, and the count says so, for example "12 selected (3 hidden)"; Move and Delete still include them, and their warnings give the full number. In the desktop app for now.
- 🚚 **Moving many cards is quick** — moving a big selection into a folder (or back out) now happens in one go instead of card by card, so the library no longer redraws once for every card. In the desktop app, and when you move cards from the phone or a browser.
- 🖱️ **Pick cards with the mouse** — in the library, a quick drag over the grid draws a box and picks every character and group chat it touches; hold Ctrl (Cmd on a Mac) to add to what is already picked. Shift-click picks every card from the last one you clicked, and Ctrl/Cmd-click picks or unpicks one card without opening it. The box scrolls the grid near the top and bottom edges. In the desktop app.
- 📦 **Drag your picks into a folder** — press and hold a picked card, then drag: every pick comes along, shown as a small stack with the count, and the picked cards fade while you drag. Drop them on a folder, which says "Drop to move 3 here", or on any level of the folder path at the top ("My Characters" or a folder above the one you are in), and they all move in one go. Holding a card you have not picked still moves just that card, and Esc calls a drag off. In the desktop app.
- 💾 **KoboldCpp keeps less memory for chats you have left** — the chat you have open is always kept ready in memory, so a reply after a Realism check starts at once (nothing decides whether it is worth it any more), and that memory is freed when you leave the chat (another chat, another character, or back to the library). If you switch between a few chats, **Keep recent chats ready** keeps up to four of the ones you used last ready too, so going back to one is quick: Settings → Advanced → Advanced Launch Options on the desktop, or Settings on the phone.
