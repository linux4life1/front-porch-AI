# Rawhide — What's New (Nightlies)

These notes are the in-app "Update Available" text for Rawhide builds. The
nightly takes every bullet under **Unreleased** as that build's release
body, and `tools/rotate-rawhide-notes.sh <tag>` then removes the bullets it
shipped, so a note is read here once and lives on in the GitHub release.
Write one bullet per change, on one line, with a bold title. Nothing else
goes in this file; `test/hygiene/rawhide_notes_test.dart` checks that.

Last shipped nightly: `nightly-rawhide.20261101.6274933`

## Unreleased

- 👥 **Edit group is a page, and editing a member is the 1:1 editor** — Group Settings is gone: "Edit group…" opens a page with the same Details, Dialogue, Lorebook and Worlds tabs as a character, including new group fields (Personality, Post-History Instructions, Tags, Example Dialogue, story start, Realism Verification) and your stats together. Editing a member opens the character editor you know, with a note that the group keeps its own copy, Time & Day, Worlds, Chaos and Realism Verification greyed out because the group sets them, and the member's group prompt, author's note and starting feelings at the end. Add, remove and bring back members without opening the chat, and Duplicate Group now really copies a group. Member Reset, Reset ALL and the memory importance sliders are gone. Your groups keep every setting they had. On the desktop and the web app.
- 🪞 **The web app matches the desktop** — The web character editor, home toolbar, menus and navigation now show the same sections, buttons and wording in the same order as the desktop: Home's Chats / Porch Stories toggle, User Persona in the nav, Remote Access under Settings, Avatar Gallery from the character menu, and lorebook entries edited in a dialog.
- 🧠 **Group memory belongs to each character** — In a group, a character now remembers only what they were there for: a scene they were Away for stays unknown to them, and their memory is theirs alone (plus their own Data Bank and memory sources). Chats you already have keep the memories they made. The Memory section now shows in a group for the character you tapped, and a group's memory runs only while Memory is on in general and on for the group (its switch greys out otherwise). On the web app its switch controls the group's memory instead of the 1:1 setting, and the web app's Memory section gains the Sources picker and the Data Bank (add, edit, delete, import, embed) for the character you tapped. On the desktop and the web app.
- 🎚️ **Realism, Needs and Afterglow per character in a group** — In a group, the Realism switch in Character State, the Needs line and the Afterglow line now belong to the character you tapped, on the app and the web: turn Realism off for one and only the others are scored, turn Needs off for one and the rest keep ticking. Chats you already have behave as before, and a character's Afterglow switch on their card in the group is what new chats start with.
- 🫂 **A group chat's sidebar reads like a 1:1** — Tap a character in a group and Character State shows their bond bars, fixation, Needs, ambitions, Pockets and time, exactly as a 1:1 does, instead of a member card; Objectives and the AFK switch now show in groups too. A new read-only Group Dynamics section under it lists how that character feels about each of the others. The group's editor moved into Main Settings, "Group Author's Note" is just "Author's Note", and the voice call button stays in a group, greyed out, with a "1:1 only" tooltip. On the desktop and the web app, except that the web app has no voice call and no AFK switch in its sidebar.
- 🚪 **Away and Back on the cast chips** — In a group, the button that sends a character away or brings them back now sits on their face in the cast strip, as it does in the web app, and the time portion follows the same rule as a 1:1 chat.
- 📥 **Backyard AI chats come across whole** — Importing a Backyard AI export now brings every chat you had with that character, not just the first, each starting with its opening message and keeping every reply you regenerated as a swipe (showing the one you had picked). Like any new chat, it asks which persona you were, and marks the one the chats call you by as Recommended. On the desktop and the web app.
- 🎛️ **Generation presets that follow the model** — Save the Generation values as named presets, load one back, and link a preset to a model so switching to that model loads it, from Settings or from the chat. A model with no preset starts from its own recommended samplers, read from the model file, the provider or a built-in list of model families, and a toast offers Undo. Each value has a reset button that puts back the model's recommended value. Chat Settings can load a preset into one chat, and the web app's Chat settings now has the same per-chat Generation section as the desktop. On the desktop and the web app.
- 📔 **Newest memories on top** — The Journal and Our Story now list the latest entry first, with pinned memories still at the top, so you no longer scroll to the bottom to see what just happened. On the desktop and the web app.
- 👆 **Manual Reprocess out of your thumb's way** — On a phone or tablet the web app's Manual Reprocess and Revert buttons now sit at the end of the top row of Realism chips under the last reply, instead of on their own row just above the message buttons where they caught stray taps. The desktop app and the web app with a mouse are unchanged.
- 🌅 **The sky follows the story clock** — With Ambient scene on, the stage behind the chat now blends the time-of-day wash by the minute instead of snapping at each part of day, and adds a sun by day, a moon with its phase and stars by night, and a warm band at dawn and dusk. Thick weather dims the sun and moon into a wider glow and thins the stars, but never hides them. With Tint and effects on, the stars twinkle and a jump in the story clock (a sleep, days passing) plays a short time-lapse; Tint only keeps the sky still, and so does Reduce motion. The sky moves only when the story clock does, never on its own. On the desktop and the web app.
- 🎭 **Mood on the character** — A new Appearance setting paints each character's Realism state on what they own: the sidebar portrait gets a ring in their mood's colour that burns, breathes, jitters, bounces, beats or crackles with the mood and bursts when it changes, a halo for the bond and a weight for the trust, and a breathing rim when a need is in trouble; a needs bar in trouble throbs in its own colour with a badge, twice as fast when critical, and a character who enjoys low hygiene gets that bar the other way round; at the full level the latest reply wears its mood too. Off by default, with a Drama slider, under Chat Appearance, shown only while Porch Life's Realism Engine is on. It never touches the weather behind the chat. Reduce motion holds it still. The Appearance tab's weather controls now sit under their own Background weather heading, shown only while Story Weather is on. On the desktop and the web app.
- 🎡 **Chance Time, with weight** — The Chance Time wheel now runs on the Ambient Stage's engine. The pointer clicks on every peg and trembles on the last one, carnival bulbs and sparks run with the wheel's speed, the wheel shakes, pops and flashes when it lands and throws out the slot's emoji, and the reveal plays in the result's own key: confetti for Fortune, a red dim and falling ash for Misfortune, lightning for Chaos, a purple shimmer for Wild Card. The event is still decided before the wheel moves. Reduce motion jumps straight to the card. The phone's Chance Time gets the same wheel where it had a flat card. On the desktop and the web app.
- 🪪 **Your bubbles show the right persona** — With several personas sharing a name, your own messages showed the avatar of whichever one was made first, while the input bar showed the one you chose. Each message now remembers the persona that sent it, in 1:1 and group chats, and older messages show the chat's own persona.
- 🖼️ **Image Studio remembers what you made** — Every Create and Edit result now lands on a Recent shelf under the result, kept on disk, so closing the Studio, leaving the page or restarting the app no longer loses a picture you forgot to save. Tap one to bring it back with its prompt; star it so it is never trimmed, send it to Edit, or delete it. The shelf keeps the last 50 by default (200, Keep all or Off in its picker), and the desktop can move it to a folder of your choice. The desktop and the web app share one shelf.
- 🏷️ **@ names stay out of the chat** — Typing @Name in a group chat (or to a Scene Guest) still picks who answers next, wherever the @Name sits in your line, but the @Name no longer shows in your bubble or reaches the model. A line that is only @Name just makes them speak, with no empty bubble. On the desktop and the web app.
- 🎒 **Pockets, per conversation** — A switch on the sidebar Pockets & Wardrobe row now turns inventory and wardrobe tracking off for one chat. Turning it off asks first and says what it means: the record is kept, not erased, nothing is tracked while it is off, and there is no catch-up when you turn it back on. Group chats get a switch on each member so you only silence the one you mean, a character’s editor switch is now the starting choice for new chats, and Group Settings carries the group’s default. On the desktop and the web app.
