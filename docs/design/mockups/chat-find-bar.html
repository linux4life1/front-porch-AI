Mapping to the codebase & locked decisions

  • Active match = AppColors.porchHoney #E9C46A — the same tint language as the existing JumpFlash. Faint tint on every other match; bubble flashes (1.8 s) when the find lands, reusing that component.
  • Visible-scope only. The collapsed thinking block above contains "lantern" and is NOT highlighted or counted; hidden swipe pills mark that branches are out of scope. Search runs on displayText + sender name.
  • Highlight plumbing: leaf-span split inside StyledChatMessage._buildStyledText (HTML <mark> ≈ TextSpan background), delivered via a FindHighlightScope inherited widget — zero cost when find is closed.
  • Backfill wait (state 2): if isBackfillingHistory, the bar awaits _awaitHistoryHydrated() with spinner + page progress; input stays editable, results land when hydration finishes. No partial counts — per your call.
  • Counter is honest ("2 / 13"); the unbounded-vs-"999+" cap is still your open question. No-match uses logError #FF6B6B.
  • Sender-name matches light the bubble header too (proposed; the Journal receipt jump on the right shows the existing jump machinery this reuses).
  • Web parity: identical bar; matches come from GET /api/chat/search?q=… (same Dart scan), <mark> spans in the React renderer, same span-window revealAround equivalent.
  • Wildcards (word-anchored globs): *dog → bulldog ✓ but dogwood and dogs ✗ (the word must end in dog — use *dog* for contains); cook* → cook, cookware, cooking ✓ but undercook ✗; cook*ware → cookware ✓, not across spaces. A * matches word characters only, and the match locks to whole words — naive .* would make *dog no better than typing dog. \* searches a literal asterisk (action text contains real *s — try it). No star typed → plain substring, unchanged. Counter caps at 999+ (locked). Boundary checks are manual (no lookbehind) so the Dart RegExp can mirror this engine exactly.
  • Regex mode (.* toggle, included): input is taken verbatim as an ECMAScript RegExp — alternation (lantern|Biscuit), the cross-space window lantern.*storm, classes, anchors, groups. Same compile pipeline as globs, so ranges, highlighting, navigation and the 999+ cap are unchanged downstream. Invalid pattern = red glow + bad pattern live as you type. In this mode * is a regex quantifier, not a glob (wildcard chip only shows in glob mode). ReDoS blast radius is one message bubble per scan. Aa toggles case-sensitivity (default: insensitive). Dart compiles with unicode: true so \p{...}/\w match JS. The route gains a mode param.
  • Colors/fonts: background #1B1611, card #251E17, AI bubble #374151, user bubble #3B82F6, dialogue #FFD54F, action #90CAF9, 14 px reading base · 1.4 leading (kReadingFontSize).
  • Keys: ⌘/Ctrl+F opens (raw-key handler pattern from chat_page.regen_shortcut.dart so composer focus can't eat it); ↵/⇧↵ navigate; Esc closes; session switch auto-closes.
